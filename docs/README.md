# Portfolio — Planning Docs

Planning for Divyanshu Kubde's portfolio. Written 24 Nov 2026, before any code.

**Concept (v2):** the portfolio is a manga volume and every project is a chapter. Bone paper, heavy black ink, one blood-red brush stroke, giant condensed type, and motion that hits like an anime cut. Style comes from Berserk, Vinland Saga, Attack on Titan, Jujutsu Kaisen and Chainsaw Man; nothing is copied from them. Interaction ideas are adapted from quicklive.tech. Colour: **Blood** by default, **Aged** as the alternate.

The first concept (soft animation paper, "frame by frame") was rejected and replaced on 24 Nov 2026.

## The flow

```
0 Discovery ✅ → 2a Colour + type ✅ → 1 Foundation → 2b Moving hero → 3 Opening → 4 Work
→ 5 Rest of the film → 6 Mobile cut → 7 Test → 8 Critique ×2+ → 9 Ship
```

Content and structure first, look second, spectacle third. Each stage ends at a gate that can be looked at and judged.
